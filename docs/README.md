# Design System

## Theme

The Hill Recipes application uses a light theme with blue as its primary color.

### Color palette

| Name | Hex value | Usage |
|---|---|---|
| Primary | #1565c0 | Buttons, accents and highlights |
| Secondary | #42a5f5 | Secondary elements |
| Background | #f5f8fc | Application background |
| Surface | #ffffff | Cards and content containers |
| Text | #263238 | Main text |
| Muted | #64748b | Secondary text |

## Typography

- Font family: Inter
- Font weights: 400, 500, 600, 700

## Shared Components

The following reusable Angular Material components have been created:

- RecipeCard
- IngredientPicker
- ConfirmDialog
- AdminTable

Each component has its own HTML, TypeScript and CSS files.

## Testing

All four components are displayed on the `/shared-test` route.
